УСТРАНЁННЫЕ ЕДИНЫЕ ТОЧКИ ОТКАЗА

  UserGate файла moscow_boundary.geojson размером 24 105 байт.

- скрипты интерфейса предварительно загружаются на экране входа без выполнения.
- успешный вход не блокируется на фоновой очистке записи rate-limit.
- API Яндекс Карт загружается параллельно с защищёнными данными после входа.
- фотографии выдаются только после авторизации через Netlify Blobs cache;
  прямой Nextcloud остаётся резервным маршрутом.

РЕЗЕРВНЫЕ КОНТУРЫ
- авторизация: два запроса с 10/25-секундными ограничениями;
- локальные компоненты: fetch с AbortController и безопасным повтором;
- данные: быстрый Netlify Blobs cache -> защищённая встроенная копия;
- актуальность: фоновая проверка Nextcloud после построения интерфейса;
- карта: два независимых сетевых запуска и ручной повтор;
- восстановление сети: автоматический повтор входа либо карты по событию online.
- запись Excel: operationId -> синхронная попытка -> фоновый повтор pending;
- конфликт ETag: отдельное состояние conflict без слепых повторов;
- резервирование: уникальная копия перед каждой записью, хранение 30 версий.

ИТОГ
При доступном домене Netlify пользователь получает лёгкий экран входа, а
остальные части загружаются отдельными запросами с повторами.
Сбои Nextcloud, Яндекс Карт и отдельных последующих запросов больше не приводят
к пустой странице. Полная блокировка домена сетью остаётся инфраструктурным,
а не программным ограничением.

- добавлен защищённый /api/photo с памятью, Netlify Blobs, ETag и private cache;
