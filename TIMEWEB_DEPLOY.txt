ФОТОМОНИТОРИНГ ОБЪЕКТОВ — ПИЛОТ TIMEWEB

ЧТО ЭТО
Это RC5 Fast Load, адаптированный для Timeweb Cloud App Platform. Интерфейс,
авторизация, карта, чтение Excel, фотографии и админ-режим сохранены. Вместо
Netlify Functions используется один постоянно работающий Node.js/Express-сервер.

ПЕРЕД ДЕПЛОЕМ
1. Создайте закрытый репозиторий GitHub, GitLab или Bitbucket.
2. Поместите в него содержимое этой папки, а не сам ZIP-файл.
3. Не добавляйте .env, реальные пароли, токены и node_modules.
4. Netlify-сайт testp360 не удаляйте: он остаётся рабочей резервной версией.

СОЗДАНИЕ ПРИЛОЖЕНИЯ В TIMEWEB CLOUD
1. App Platform -> Создать приложение -> Backend -> Node.js -> Express.
2. Подключите репозиторий и выберите нужную ветку.
3. Путь к директории проекта оставьте пустым, если package.json находится в корне.
4. Версия Node.js: 22.
5. Регион: Россия. Для Москвы выбирайте доступный московский регион.
6. Команда запуска: npm start. Файл server.js также распознаётся автоматически.
7. Путь проверки состояния: /health.
8. Включите автодеплой только после первого успешного теста.

ПЕРЕМЕННЫЕ
Перенесите из Netlify все существующие значения. Обязательный минимум:
  DASHBOARD_ACCESS_PASSWORD
  DASHBOARD_ACCESS_TOKEN_SECRET
  DASHBOARD_ADMIN_PASSWORD
  DASHBOARD_ADMIN_TOKEN_SECRET
  YANDEX_MAPS_API_KEY
  NEXTCLOUD_EXCEL_URL

Для двусторонней записи также нужны:
  NEXTCLOUD_EXCEL_WRITE_ENABLED=true
  NEXTCLOUD_EXCEL_WRITE_SHARE_URL
  NEXTCLOUD_EXCEL_WRITE_SHARE_PASSWORD — только если ссылка защищена паролем

Полный безопасный шаблон находится в .env.example. Сам .env в репозиторий не
загружайте: переменные добавляются в панели Timeweb.

ПРОВЕРКА
1. Откройте выданный технический HTTPS-домен Timeweb в инкогнито.
2. Проверьте неверный и верный обычный пароль.
3. Проверьте показатели, карту и одну фотографию дважды.
4. Пять раз нажмите на значок камеры, войдите как администратор.
5. Для записи статуса используйте тестовую строку Excel и убедитесь, что статус
   появился в рабочем dashboard_data.xlsx на Nextcloud.
6. Откройте /health: сервер должен вернуть JSON с ok=true.
7. Только после проверки заменяйте ссылку в родительском дашборде.

ВАЖНОЕ ОГРАНИЧЕНИЕ ПИЛОТА
Кэш данных, фотографий, счётчик неудачных входов и временные резервные копии
хранятся в файловой системе контейнера. Они переживают обычную работу процесса,
но могут быть сброшены при полном редеплое приложения. Основной Excel остаётся
в Nextcloud и не теряется. Для постоянной эксплуатации резервные копии и кэш
следует перенести в Timeweb S3.

КЛЮЧ ЯНДЕКС КАРТ
После получения технического домена Timeweb добавьте этот домен в разрешённые
домены ключа JavaScript API Яндекс Карт. Старый testp360.netlify.app пока не
удаляйте из ограничений.
