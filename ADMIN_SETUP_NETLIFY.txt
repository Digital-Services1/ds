НАСТРОЙКА NETLIFY ДЛЯ ВЕРСИИ 2.0.7

ДЛЯ RC5 FAST LOAD
Новые переменные не обязательны. При переносе папки фотографий можно задать:
  NEXTCLOUD_PHOTO_PUBLIC_FOLDER_URL
  NEXTCLOUD_PHOTO_VERSION
Значения должны совпадать с nextcloudPublicFolderUrl и nextcloudPhotoVersion
в config.source.js. В текущем релизе используются встроенные прежние значения.

Откройте:
  Netlify -> Project configuration -> Environment variables

Добавьте новые переменные:

  DASHBOARD_ACCESS_PASSWORD = пароль для обычного входа в дашборд

  DASHBOARD_ACCESS_TOKEN_SECRET = случайная строка не короче 32 символов

  YANDEX_MAPS_API_KEY = ключ JavaScript API Яндекс Карт

Для каждой переменной выберите All scopes и одинаковое значение во всех
контекстах. После сохранения выполните новый Production deploy.

Ключ Яндекс Карт всё равно становится доступен браузеру после авторизации:
это нормальная работа JavaScript API. В кабинете Яндекса обязательно оставьте
ограничение ключа по домену:
  testp360.netlify.app

СУЩЕСТВУЮЩИЕ ПЕРЕМЕННЫЕ НЕ УДАЛЯТЬ

Чтение рабочего Excel:
  NEXTCLOUD_EXCEL_URL = прямая HTTPS-ссылка на скачивание рабочего dashboard_data.xlsx

Двусторонняя запись:
  NEXTCLOUD_EXCEL_WRITE_ENABLED = true
  NEXTCLOUD_EXCEL_WRITE_SHARE_URL = публичная HTTPS-ссылка /s/<token> на тот же рабочий файл

Если публичная ссылка защищена паролем:
  NEXTCLOUD_EXCEL_WRITE_SHARE_PASSWORD = пароль публичной ссылки

Админ-режим:
  DASHBOARD_ADMIN_PASSWORD = отдельный пароль администратора
  DASHBOARD_ADMIN_TOKEN_SECRET = отдельная случайная строка не короче 32 символов

КАК ПРОВЕРИТЬ ПОСЛЕ ДЕПЛОЯ

1. Откройте сайт в режиме инкогнито.
2. Убедитесь, что неправильный обычный пароль не пропускает.
3. Введите DASHBOARD_ACCESS_PASSWORD.
4. Проверьте загрузку показателей и Яндекс Карт.
5. Пять раз нажмите на вращающийся значок камеры.
6. Введите DASHBOARD_ADMIN_PASSWORD и поменяйте один заранее выбранный проверочный статус.
7. Нужное сообщение:
   «Статус сохранён в Excel на Nextcloud».

АВТОМАТИЧЕСКИЙ ПЕРИОД

Период рассчитывается по Europe/Moscow со сверкой часов по времени сервера:
- до среды 23:29 действует период от предыдущей среды;
- в среду 23:30 начинается период от текущей среды;
- конец периода — следующий вторник включительно.

Ячейки B4, D4 и F4 листа «План недели» можно сохранить для Excel-отчёта,
но на период в дашборде они больше не влияют.

ВАЖНО
- Обычный пароль не хранится в config.js и не передаётся обратно браузеру.
- Сессия обычного входа хранится в Secure HttpOnly cookie 12 часов.
- Ключ Яндекс Карт возвращается только после успешного входа.
- Администраторский пароль и обычный пароль — независимые переменные.
- Перед каждой записью создаётся отдельная резервная копия Excel; сохраняются
  последние 30 версий и указатель latest-before-write.xlsx.
- После успешной записи Excel снова становится главным источником статуса.
- Если Nextcloud временно недоступен, фоновая функция повторяет запись автоматически.
- В архиве нет действующих ссылок и токенов Nextcloud. Значения задаются только
  через переменные Netlify.
